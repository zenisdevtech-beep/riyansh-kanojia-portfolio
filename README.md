# Developer Portfolio — Next.js

A modern, dark developer portfolio starter built with Next.js, TypeScript, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js 20+.
2. Extract this folder and open it in a terminal.
3. Run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Personalize before publishing

In `app/page.tsx`, update:
- Name / intro text and availability status
- Project titles, descriptions, tags, and destination links
- GitHub and LinkedIn URLs
- `hello@yourdomain.com` in the contact section and `copyEmail` function

Update the page title and description in `app/layout.tsx`.

## Stack
- Next.js App Router
- TypeScript
- CSS (responsive, no UI framework required)
- Framer Motion
- Lucide React

The project artwork is created with CSS and HTML elements, so no stock images are required.
